## Uwaga o zakresie

Ekrany 18–29, 30 i 37 opisują moduł wystawców (`Exhibitors`, `Items`,
`Exhibitor Marketplace`, `Exhibitor Center`), który decyzją zamawiającego
(§0.4 dokumentu projektowego) jest **poza zakresem** — partnerzy i sponsorzy
idą z CRM firm. Zrzuty zostają jako materiał porównawczy, nie jako zadanie.
