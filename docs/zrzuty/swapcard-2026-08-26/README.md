# Partia: Swapcard Studio, zebrana 2026-08-26

Katalog na kolejne zrzuty. Konwencja nazw i zasady - `docs/zrzuty/README.md`.

Najbardziej przydatna kolejność (tam jest już backend, brakuje powierzchni 1:1):

1. `In-App registration` - formularz zapisu, typy wejściówek, akceptacje
2. `Content` - sesje, ścieżki, sale, prelegenci, dokumenty
3. `Onsite` - punkty kontroli, skaner, badge'e, lead retrieval
4. `Communications` - kampanie, sekwencje, powiadomienia

Ekrany już odwzorowane (Informacje ogólne, Strony i menu, Grupy i uprawnienia,
Branding) opisuje sekcja „Stan wdrożenia" w
`docs/MAPOWANIE_SWAPCARD_EVENT_BUILDER_ZRZUTY.md` - zrzuty do nich są potrzebne
tylko wtedy, gdy coś się nie zgadza z opisem.
